## 💡 О проекте

Мы помогаем учащимся экономить время и нервы, профессионально оформляя курсовые, дипломы и рефераты по ГОСТу, структурируя их черновики и создавая эффектные презентации для защит.

> **Мы не пишем работы за студента.** Мы делаем его собственные наработки идеальными и соответствующими требованиям вуза.

---

## 🛠 Услуги

- 📄 **Оформление по ГОСТу** — приведение готового текста в соответствие с требованиями вуза
- 🧩 **Структурирование из черновиков** — превращение заметок в логичный документ
- 📊 **Дизайн учебных презентаций** — стильные презентации для защиты
- 🎓 **Проект под ключ** — комплексная помощь: структура + оформление + презентация + речь

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Сайт откроется по адресу: http://localhost:5173

### Сборка для продакшена

```bash
npm run build
```

Готовые файлы появятся в папке `dist/`.

### Предпросмотр собранной версии

```bash
npm run preview
```

## 📦 Деплой

### Netlify (проще всего)

1. Соберите проект: `npm run build`
2. Перетащите папку `dist/` на [netlify.com](https://netlify.com)
3. Готово! Сайт доступен по ссылке

### GitHub Pages

1. Создайте репозиторий на GitHub
2. Отправьте код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/USERNAME/gostify.git
   git push -u origin main
   ```
3. Настройте GitHub Actions (см. `.github/workflows/deploy.yml`)
4. Включите Pages в Settings → Pages → Source: GitHub Actions

### Vercel

1. Импортируйте репозиторий на [vercel.com](https://vercel.com)
2. Нажмите **Deploy**
3. Готово!
